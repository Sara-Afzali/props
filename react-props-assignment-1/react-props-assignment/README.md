# LearnHub — React Props Assignment

A responsive React + Vite project demonstrating reusable components and props.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open the terminal in this folder and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite.

## Build for deployment
```bash
npm run build
```
Upload the project to GitHub, then import the repository into Vercel or Netlify to publish it.

## Reusable components
Navbar, SectionHeading, CourseCard, InstructorCard, FeatureCard, TestimonialCard, Notice, PrimaryButton, StatCard, and Footer.

Repeated data such as courses, instructors, features, and statistics is rendered with `map()`. Each component receives props and uses them in its JSX.
